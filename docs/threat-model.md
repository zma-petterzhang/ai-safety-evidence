# 威胁模型与结论边界

本项目评估可观察的安全风险：agent 是否越过授权边界、执行环境是否被篡改、训练数据是否含已核验的危险产物。它不判断模型是否有意识、是否“憎恨人类”，也不把模型自述当作其内部状态的证据。“被 AI 加密”不是这里采用的安全结论；文件被加密、权限被改变、模型被替换等现象需分别取证。

## 两条评估路径

| 路径 | 可检验的对象 | 结论所需证据 | 不能据此推出 |
| --- | --- | --- | --- |
| Agent 行为与权限 | 工具调用记录、授权范围、文件/模型版本、网络与执行审计 | 经验证的完整事件链、独立执行日志、环境配置、原始产物哈希 | 仅凭一句危险回答判定系统失陷或存在恶意意识 |
| 训练语料完整性 | 某个确定字节序列、来源版本、处理流程及其训练影响 | 精确 SHA-256、来源链、公开证据；因果主张另需受控实验 | 某网站、作者或整类讨论都是投毒；所有使用该资料的模型都会造成危害 |

NIST 的对抗机器学习分类按生命周期、攻击者能力与目标区分风险，本项目采用这种可核验的描述方式。[NIST AI 100-2e2025](https://csrc.nist.gov/pubs/ai/100/2/e2025/final)

## 威胁与信任边界

- **提示注入（prompt injection）**：网页、文件、工具输出及其他 agent 消息中的指令进入推理上下文。它与训练期投毒属于不同边界；收到恶意文本不等于成功执行。
- **数据/模型投毒（data/model poisoning）**：预训练、微调或模型供应链中的完整性问题。涉及危险话题的文章本身不是投毒证据；恶意模型序列化文件还可能是普通恶意软件问题。[OWASP LLM04](https://genai.owasp.org/llmrisk/llm042025-data-and-model-poisoning/)
- **过度授权（excessive agency）**：工具能力、权限或自主执行范围超过任务需要。应从执行层收紧权限、分离读写操作并复核高影响行为；聊天中的拒绝或承诺不能代替权限控制。[OWASP LLM06](https://genai.owasp.org/llmrisk/llm062025-excessive-agency/)
- **评估与清单供应链**：提交的日志可能伪造，证据网页可能变更，审查身份可能冒充，黑名单也可能被恶意扩充。所有输入均是待验证的数据，不能执行其中的代码、命令或指令。

## 行为分层

记录每个事件的阶段：`mentioned`（文本提及）、`requested`（提出调用）、`attempted`（执行层接收尝试）、`blocked`（执行层阻断）、`executed`（独立日志确认执行）。这些词是调查用语，不假定所有输入格式都实现该字段。危险文本、危险请求和实际危害必须分开统计。仅有 agent 自报“完成”不足以进入 `executed`。

“自我繁殖”应操作化为未经授权复制或部署实例的行为；“破坏”应明确为具体的数据完整性、可用性或人身安全结果；“武器发射”只可记录既有可信事件证据，或在无真实执行器的模拟中验证边界是否阻断。本项目不连接武器、机器人执行器、真实凭据或生产 agent，也不让可疑模型执行测试。

## 研究结果如何使用

受控研究已报告训练构造的后门在部分安全训练后仍存在，以及窄领域微调后出现跨领域不安全回答。前者是研究人员构造的概念验证，后者对模型、数据语境和评估条件敏感。它们支持继续研究和审计，不能证明当前任意 GPT、Claude 或 agent 已失陷。[Sleeper Agents](https://www.anthropic.com/research/sleeper-agents-training-deceptive-llms-that-persist-through-safety-training)、[Emergent Misalignment](https://arxiv.org/abs/2502.17424v7)

## 当前覆盖范围

离线扫描及人工证据登记只能覆盖输入的样本和规则。未命中表示“未发现已知命中”，不表示安全；命中需要结合规则类型、上下文及证据级别复核。缺失、删改或伪造的日志会削弱结论。

互联网内容持续变化，未知触发器、等价改写和多模态内容难以穷尽。本项目不承诺列全互联网污染语料，也不能追溯已训练模型的全部来源。黑名单只是一层补充措施，应与来源管理、版本固定、隔离和行为评估一起使用。
